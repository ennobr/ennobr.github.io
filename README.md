# ennobr.github.io

Personal research website of Enno Breukelman.

This repository publishes the public website at:

https://ennobr.github.io

## Editing notes

- Edit the homepage bio, buttons, and portrait settings in
  `content/profile.json`.
- Edit recent updates in `content/news.json`.
- Edit current work cards in `content/projects.json`.
- Edit selected publications in `content/publications.json`.
- Edit email and social links in `content/contact.json`.
- The publication section links to Google Scholar, but renders from local data
  because Google Scholar does not support reliable browser-side syncing from a
  static GitHub Pages site.
- The page layout lives in `index.html`, styling lives in `styles.css`, and the
  content loader lives in `scripts/site-content.js`.
